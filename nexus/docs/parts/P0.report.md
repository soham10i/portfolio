## 2. Deviations from the brief

- **D1. asyncpg instead of `psycopg[binary]`.** psycopg is LGPL-3.0, which the brief's
  licence rule forbids. Recorded in ADR-0007 and OPEN_QUESTIONS Q8. The DB test casts the vector to
  text (`'[1,2,3]'::vector::text`) because asyncpg has no `vector` codec.
- **D2. Parity check.** Semantic-only examples are listed explicitly, as the brief asks. For
  those, the test also asserts that the model *accepts* the document. For all others the verdicts
  must match (Q3).
- **D3. `ValidationIssue` field order** is `(pointer, code, message)`, not `(code, pointer, message)`,
  so the dataclass sorts by pointer (Q6).
- **D4. Self-compensation is allowed.** `SELF_COMPENSATION_LOOP` fires only for cycles through
  another action (Q1).
- **D5. Expectation sidecars** are named `X.expect.json` next to `X.<kind>.yaml`, so the CLI
  does not pick them up as documents. `X` is the part before the kind suffix.
- **D6. An `action` kind** is accepted by the CLI and has an example (`echo-say.action.yaml`), in
  addition to the five kinds the brief lists for file naming. `Kind` has the six kinds §4 names.
- **D7. The YAML loader** is a `SafeLoader` without implicit timestamps (Q5). It is still a
  safe loader.
- **D8. One extra ADR** (0007) beyond the six the brief lists.
- **D9. The STF envelope key** is `temp_ramp_degc_per_minute`, not `…_per_min`, because of the
  `_min` suffix rule (Q2).

## 3. Open questions added

`docs/OPEN_QUESTIONS.md` Q1–Q8: self-compensation, envelope suffixes, the parity method,
semantic rules on invalid documents, YAML timestamps, `ValidationIssue` field order, licence
strings, and the psycopg licence.

## 4. Suggestions for P1

- Pick the runtime Postgres driver first (Q8). ADR-0007 assumes asyncpg, so P1's store code is async.
- Implement JCS (RFC 8785) hashing against published test vectors before the event table. The
  schema already documents `hash = sha256(JCS(event without "hash"))`.
- Make the envelope structured (Q2) before P2 starts evaluating it. That is a breaking change,
  cheaper while no pack exists outside this repository.
- CI is not yet proven on GitHub: the workflow was linted only as YAML locally, and the action
  SHAs were resolved with `git ls-remote` (checkout v7.0.1, setup-uv v10.3.3). The first push
  will show whether it runs.
