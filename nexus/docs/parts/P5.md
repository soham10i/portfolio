# P5 — Model router

**Status:** built, awaiting review (see `P5.report.md`) · **Estimate:** 1 week · **Milestone:** M2 (1 of 5 parts)
**Read first:** `../../GOAL.md`, `../INDUSTRIAL_BLUEPRINT.md` §4 (model router) and the P5 entry,
ADR-0008 (event store), ADR-0015 (model router, written with this part).

## Goal

One call, `Router.generate(task, prompt, schema, ...)`, that gets a JSON answer matching `schema`
from whichever configured model provider can give it: free cloud tiers first, local Ollama as the
fallback, paid providers never unless the owner sets a budget. Every attempt, success or not, is
an event. Nothing in P5 plans or proposes; P6 builds the planner on top of this.

---

## 0. Hard constraints

The P0–P4 constraints all still apply. In addition:

1. **No money is spent by default.** Providers are free (Gemini free tier, Groq free tier, local
   Ollama) or paid. A paid provider's daily budget defaults to 0, and a budget of 0 refuses
   every call before any request is sent. A paid provider without prices also refuses: its cost
   cannot be bounded. The per-request budget (`Budget.max_cost_usd`) also defaults to 0.
2. **Tests and CI never call a real provider.** All provider traffic goes through a `Transport`;
   tests use fakes that replay hand-written responses in each provider's documented format. A
   pytest guard makes the real transport raise in every test unless `NEXUS_LLM_LIVE=1` is set.
   The only live test is marked `live` and skips without that variable; CI never sets it.
3. **Keys come only from environment variables.** The config names the variable
   (`api_key_env: GEMINI_API_KEY`); the key is read at call time, sent in a header (never a URL),
   and never written to an event, an error message, a log line or a file. `.env.example` lists
   variable names with empty values.
4. **Private data stays local.** `generate(..., private=True)` only uses providers marked
   `private_ok`. Gemini's free tier may use what it receives to improve Google's products, so it
   is `private_ok: false`; Groq is also `false` until the owner checks its terms; Ollama is
   `true`.
5. **No new dependency.** HTTP uses the standard library (`urllib.request` in a worker thread).
   No provider SDKs.

## 2. Configuration

`models.yaml` (or the file in `NEXUS_MODELS_CONFIG`) lists providers in preference order:

| Field | Meaning |
|---|---|
| `name` | identifier used in events and `--provider` |
| `kind` | `gemini`, `openai` (any OpenAI-compatible API, e.g. Groq) or `ollama` |
| `model`, `base_url` | what to call; `base_url` must be `https://`, or `http://` on localhost only |
| `api_key_env` | environment variable holding the key; `null` for Ollama |
| `free` | `true` → prices must be 0; `false` → `daily_budget_usd` (default 0) and prices apply |
| `price_in_per_mtok`, `price_out_per_mtok` | USD per million tokens (paid only) |
| `daily_budget_usd` | paid only; 0 refuses everything |
| `max_requests_per_day` | stay inside a free tier's daily quota |
| `private_ok` | may receive `private=True` requests |
| `timeout_s`, `cooldown_s` | per request; default pause after a 429 or 5xx without `Retry-After` |

## 3. `Router.generate`

```python
await router.generate(task, prompt, schema, *, system="", budget=Budget(), private=False,
                      providers=None, session_id=None, actor=..., trace_id=None) -> Generation
```

For each provider in order, unless it is skipped (each skip is a `model.refused` event):
`NO_KEY`, `PRIVATE_DATA`, `COOLING_DOWN`, `DAILY_REQUEST_CAP`, `BUDGET_EXCEEDED` (daily or
per request). Otherwise:

1. **Reserve** in one transaction on `model_usage (provider, day)`: count the request and its
   estimated cost (prompt length / 4 + `max_output_tokens`, priced). Concurrent calls cannot
   overspend a budget or a quota.
2. **Call** through the transport. Outcomes: `ok`, `rate_limited` (429), `unavailable` (5xx,
   connection error, timeout), `error` (other 4xx, unparseable body), `invalid_output`.
3. **Settle** in one transaction: replace the estimate with the actual cost, add tokens, and
   append `model.called` (provider, model, task, attempt, outcome, HTTP status, tokens, cost,
   latency, prompt SHA-256, the output when valid, a short error).
4. `rate_limited` / `unavailable` → cool the provider down (`Retry-After`, capped at 600 s, else
   `cooldown_s`) and fail over to the next provider, adding a note.
   `error` → fail over, no cooldown.
5. `invalid_output` (not JSON, or JSON that does not match `schema`) → ask the same provider again
   with the errors, at most 2 more times; then raise `ModelError("OUTPUT_INVALID")`. No failover:
   the problem is the task, not the provider.

When no provider answers: `ModelError("NO_PROVIDER")` with every note. Events go to
`session/<session_id>`, or to the stream `models` without a session.

`Generation`: `output`, `provider`, `model`, `call_id`, `attempts`, `tokens_in`, `tokens_out`,
`cost_usd`, `latency_ms`, `notes` (the failover notes, e.g. "gemini: rate limited (HTTP 429),
cooling down 60 s").

## 4. Acceptance — P5 is done when every item passes

| # | Check | Command |
|---|---|---|
| A1 | Lint, format, `make check` | `make check` |
| A2 | Config rules: paid without a budget refuses; free with prices is invalid; keys only by env name; plain `http://` only to localhost | `pytest tests/test_llm_config.py` |

| A4 | Mocked 429 on provider A → provider B answers, with a failover note; A is then skipped while cooling down | `pytest -m integration tests/test_router.py` |
| A5 | Schema-invalid output retried at most 2 times, then a clean `OUTPUT_INVALID` error | same |
| A6 | Budget exceeded → `model.refused` BUDGET_EXCEEDED and no request sent; a paid provider with default config never receives a request; the daily request cap holds under 20 concurrent calls | same |
| A7 | `private=True` never reaches a provider without `private_ok` | same |
| A8 | Every attempt is a `model.called` or `model.refused` event; no event or error contains a key; the chain verifies | same |
| A9 | No test reaches the network: the guard makes `UrllibTransport` raise unless `NEXUS_LLM_LIVE=1`; the live test skips without it | `make test`, `make test-db` |
| A10 | `make test-db` passes 5 times in a row; no new dependency; changes only under `nexus/` and `nexus-ci.yml` | `make test-db`, `git status` |
