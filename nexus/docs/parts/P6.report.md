# P6 report: planner and critic

Date: 2026-10-31. All commands below ran from `nexus/`. Database tests used the local
`deploy/compose.yml` Postgres on :5433 (`NEXUS_DB_URL=postgresql://nexus:nexus@localhost:5433/nexus`).
**No test or CI run calls a real provider.** Unit and integration tests use scripted fakes, and the
evaluation replays `evals/planner/recordings.json`. The recording came from one opt-in live run
(§2) on the Gemini free tier, with synthetic, public requests only. Nothing is committed.

Three new decisions:

- ADR-0020: the planner proposes; code and the gate decide.
- ADR-0021: conservative model defaults, pending Q-P5-2.
- ADR-0022: the executor enforces `depends_on`.

**Q-P5-1 and Q-P5-2 are still open.** P6 depends on Q-P5-2, so ADR-0021 picks a conservative
default instead (see §3, "Flags for the owner").

## 3. Flags for the owner

1. **Q-P5-2 default (ADR-0021).** The planner is private by default:
   - `nexus ask` without `--cloud` uses only `private_ok` providers, which is Ollama alone in the
     packaged config;
   - with Ollama not running, it gives up instead of sending to a cloud tier;
   - `--cloud` is a per-call opt-in;
   - every call is free (`max_cost_usd=0`), and the router order is unchanged.

   Answering Q-P5-2 or Q-P5-1 changes this ADR, not the planner code.
2. **The eval measures Gemini Flash-Lite.** A different default model needs a new recording
   before the numbers mean anything.
3. **A YAML bug found and fixed.** `greenhouse.pack.yaml` had an unquoted key `on:`, which YAML
   parses as the boolean `true`, so the `set_lights` params schema had a key `True`. It is now
   quoted. `load_document` refuses any non-string key, with a regression test covering `on`, `off`,
   `yes`, `1` and `null`.
4. **A new executor reason code.** When a dependency has not succeeded, the refusal code is
   `DEPENDENCY_PENDING`, with one `DEPENDENCY_NOT_SUCCEEDED` reason per missing proposal
   (ADR-0022). The gate does not check dependencies.
5. **Nothing is committed.**
