# P4 — Echo pack, evidence packs, `nexus trace`, lifecycle demo

**Status:** built, awaiting review (see `P4.report.md`) · **Estimate:** 0.5 week · **Milestone:** M1 (5 of 5 parts)
**Read first:** `../../GOAL.md`, `../INDUSTRIAL_BLUEPRINT.md` §4.7 and the P4 entry, `P3.md`,
ADR-0012 (execution), ADR-0013 (approvals), ADR-0014 (pack layout).

## Goal

Close milestone M1: one command, from a clean clone and a local Postgres, walks a proposal
through every outcome the kernel has (ALLOW, DENY, NEEDS_APPROVAL → approve → execute → verify),
explains each one afterwards from the event log alone, and shows that editing that log is caught.

P4 contains **no HTTP, no LLM, no new connector kind and no UI**. The echo pack is the only real
pack; its binding writes to stdout.

---

## 0. Hard constraints

The P0–P3 constraints all still apply. In addition:

1. **Evidence is derived, never stored.** An evidence pack is rebuilt from events (and the
   `executions` projection) every time it is asked for. Nothing new is written to explain an action.
2. **It validates.** Every evidence pack built for a schema-valid proposal validates against
   `evidence-pack.schema.json`.
3. **A manifest cannot choose arbitrary code.** Bindings load only from allowed module prefixes
   (ADR-0014).
4. **The demo is local and repeatable.** It needs only the compose Postgres, uses its own schema
   (`nexus_demo`, recreated each run) and never touches other schemas.
5. **No new runtime dependency.**

## 2. Echo pack

`EchoBinding.execute(request)` for `echo.say` writes `echo> <text>` to its output stream (stdout
by default) and remembers the text; any other action raises `BindingError`. `observe()` returns
`{"echo.last_message": text}` once something was said, else `{}`. The binding holds no other state;
a new process starts empty, so the demo seeds nothing.

`load_binding(pack)` requires `connector.kind == "python"` and a module under an allowed prefix
(default `nexus_packs.`), imports it, and calls `create_binding(pack)`. Anything else raises
`PackError`-like `BindingLoadError` before any import.

## 3. Evidence pack

`build_evidence(store, id)` accepts a decision id, a proposal id (its latest decision) or an
idempotency key, and returns:

| Field | From |
|---|---|
| `proposal`, `decision` | the `decision.made` event |
| `checks` | the gate's checks in order (below), then `approvals`, `recheck` |
| `approvals` | the `approval.granted` events that count (P3 `approval_state`) |
| `execution` | the `executions` row; `compensation_failed` → `failed`, refused / shadowed / none → `not_run`; the error as a reason (`EXECUTION_FAILED`, `COMPENSATION_FAILED`, or the refusal code) |
| `verification` | the primary `execution.verified` event (not the compensation's) |
| `event_refs` | the decision event, every event on its stream whose payload names the decision, and the `state.set` events written under those events' trace ids |
| `chain_head` | the head hash of the decision's stream when the pack is built |

Gate checks, from the reason codes (the first four stop at the first failure, so later ones are
not listed; a DENY in 5–8 means 9–10 never ran):

| # | Check | Fails on |
|---|---|---|
| 1 | `kill_switch` | KILL_SWITCH |
| 2 | `schema` | PROPOSAL_INVALID |
| 3 | `action_known` | UNKNOWN_ACTION |
| 4 | `params` | PARAMS_INVALID |
| 5 | `autonomy` | AUTONOMY_OBSERVE_ONLY, AUTONOMY_ADVISE_ONLY |
| 6 | `envelope` | ENVELOPE_EXCEEDED |
| 7 | `rate_limit` | RATE_LIMITED |
| 8 | `preconditions` | STATE_UNKNOWN, STATE_STALE, PRECONDITION_FAILED, PRECONDITION_ERROR |
| 9 | `taint` | NO_TRIGGER, TAINTED_CONTEXT, TAINTED_TRIGGER (holds for approval) |
| 10 | `risk_routing` | AUTONOMY_L2, RISK_HIGH (holds for approval) |

`passed: false` with the reason messages as `detail`. For 9–10 a failure means "a human must
approve", not "denied"; `nexus trace` prints those as `HOLD` rather than `FAIL`.

## 4. `nexus trace ID [--json]`

Prints a timeline: the proposal (action, params, proposer, rationale, trigger), the decision
(outcome, policy version, state versions read, reasons), every check, approvals, each execution
event, the verification, incidents, and finally the chain verdict for every stream the pack
references. `--json` prints the evidence pack. Exit 0 when found and every referenced stream
verifies; 1 when not found or a chain problem is found; 2 on usage or database errors.

## 5. Lifecycle demo

`uv run python scripts/demo_lifecycle.py [--no-tamper]` (also `make demo`), with `NEXUS_DB_URL`
defaulting to the compose URL:

1. Recreate schema `nexus_demo`, migrate, load the echo pack, gate, executor.
2. **ALLOW:** a user-triggered `echo:echo.say` → executes → `echo> …` → verified.
3. **DENY:** empty text → PARAMS_INVALID; the executor refuses it (`DENIED`), nothing printed.
4. **NEEDS_APPROVAL:** triggered by a document → TAINTED_TRIGGER; run → `NOT_APPROVED`; alice
   approves the exact hash; run → executes → verified.
5. `nexus trace` of the approved action, then `nexus chain verify`: intact.
6. **Tamper** (unless `--no-tamper`): as the table owner, disable the append-only trigger, edit
   the approved decision's payload, re-enable it; `nexus chain verify` reports HASH_MISMATCH and
   `nexus trace` exits 1.

It prints the commands to re-run `nexus trace` against the demo schema.
