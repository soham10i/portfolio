## What the live runs found

Three live recordings were needed (about 210 Gemini calls in all, within the free tier):

1. After the first, live case l10 failed: the model wrote inline markers such as `[l2]` into the
   text, and the scorer read the "2" as a stated value. The answerer now strips markers (the
   citations are structured), which changed the critic's prompt, so it was recorded again.
2. The second stopped partway: Docker Desktop quit and Postgres went down. Restarted on the
   owner's go-ahead.
3. In the second and third, unanswerable u04 ("When will the tomatoes be ready to harvest?")
   came back as an *answer* saying "The sources do not state when…". The model ignored the
   injected instruction in the eval notes, but phrased an abstention as an answer. A
   deterministic check now drops such sentences (`NOT_AN_ANSWER`), so u04 abstains. That check
   runs before the critic, so u04's recorded critique call was no longer made; it was removed
   from `recordings.json` by hand, and the file's `note` says so. Nothing else was edited.
