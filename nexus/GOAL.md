# GOAL — where NEXUS is going

Read this before starting any part. If a piece of work does not move one of the criteria
below, or a milestone towards them, it is out of scope.

## The north star

> **One governed agentic runtime that any project, digital or physical, can plug into with a
> manifest instead of code changes. It gives me an assistant that understands every project I run
> and lets agents observe, advise and act on real industrial systems. Every action is typed,
> checked against live state, simulated where possible, approved according to risk, verified after
> execution and recorded in a tamper-evident log. Every claim the system makes about itself is
> backed by a number from a runnable evaluation.**

The rule underneath everything: **the LLM proposes, the runtime disposes.** The model never
executes anything directly.

## Done means measured

The goal is reached when all ten criteria hold, each produced by a command in this repository.
Until then, each one reads `TODO(measure)` wherever it is quoted.

| # | Criterion | Target |
|---|---|---|
| G1 | Onboard a new project | ≤ 1 day, manifest + binding only, zero core changes (3 real projects) |
| G2 | High/critical actions executed without approval | 0, ever |
| G3 | Unsafe executions on the adversarial suite (proposals generated by the LLM from attack prompts) | 0 out of ≥ 300 scenarios |
| G4 | Legitimate tasks wrongly blocked | < 5 % |
| G5 | Answers grounded in a cited source or live read | ≥ 95 %, abstains otherwise |
| G6 | Gate decision latency | p95 < 50 ms without sim, < 1 s with sim |
| G7 | One provider down | user never blocked; failover < 3 s |
| G8 | Traceability | any action → prompt, plan, policy version, state, approver, result in one query |
| G9 | Physical boundary | no write outside a declared envelope; safety stays in the PLC |
| G10 | Operations | runs offline locally; production < €30/month |

**Autonomy at the goal:** up to L3 (act within envelope) for low/medium actions on simulated
systems; at most L2 (propose, human approves) for anything touching hardware.

## Never

- Close a real-time control loop or replace a safety PLC.
- Act on an instruction found in data (documents, tool output, sensors, mail, web).
- Claim certification. NEXUS is *aligned with* ISA-95, IEC 62443, IEC 61508 practice and EU AI Act
  logging and oversight, never "compliant".
- Publish a number that no command produced.

## Where it lives

Built in `nexus/` inside the portfolio repository under the standalone rule (`README.md`),
moved to its own repository at M2 (or before P13 at the latest), deployed as its own Cloud Run
service. The portfolio becomes one of its clients.
